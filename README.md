# 군집 분석 모델 · 시뮬레이션 + 직접 풀기

군집 분석의 기본 개념(비지도 학습, 유사성과 상이성, 계층적 군집 분석, k-평균 군집 분석, 응집도·실루엣 점수·엘보 방법)을 **시뮬레이션으로 살펴보고, 각 단계의 빈칸을 직접 채우는** 웹앱입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없고, 웹에 올릴 때는 폴더의 파일을 모두 함께 올리면 됩니다(GitHub Pages 등).

## 구성

| 단계 | 시뮬레이션 | 채우는 칸 |
| --- | --- | --- |
| 먼저 알아보기 | [표1] 성적 데이터셋(학생 10명) | – |
| 1. 군집 분석의 개념 | 할리갈리 카드 나누기(기준을 쓴 뒤 펼쳐 보기) | 빈칸, 분류/군집 분석 ○표, 나누는 기준 |
| 2. 군집화하기 | 수학·과학 그래프에서 점을 눌러 직접 묶기 | 군집 수, 군집 기준·학생 번호, 결과가 다른 까닭 |
| 3. 유사성과 상이성 | 군집 A·B·C가 만들어진 상태에서 ⑥과 다른 학생 사이의 거리, 좋은 군집 슬라이더 | 빈칸, ⑥–⑩·⑥–⑦·⑥–③ 거리 표, ⑥을 넣을 군집 |
| 4. 계층적 군집 분석 | 예제(A~E)·[표1] 수학·과학을 한 번씩 묶기, 덴드로그램, 연결법 비교 | 빈칸 |
| 5. k-평균 군집 분석 | 예제(A~E)·[표1] 수학·과학·무작위 데이터를 한 단계씩, 단계별 기록·거리표 | 빈칸, 두 방법 특징 ○표 |
| 6. 결과 평가 | 실루엣 계수 구하기(점을 고르고 끌기), 실루엣 점수·엘보 그래프와 산점도 | 빈칸, 응집도 표, 군집 수 정하기, 좋은 군집화 O/X |
| 7. 종합 연습 | – | 객관식 5문항 + 저장 |

- 빈칸 근처에는 정답이 바로 보이는 내용(바로 채점하는 연습문제, 자동으로 적히는 군집 기준 등)을 두지 않았습니다.
- 4·5단계 시뮬레이션에는 **← 이전으로** 버튼이 있어 한 단계씩 되돌릴 수 있습니다.

## 저장

- 오른쪽 위 **저장하기**(또는 Ctrl + S)를 누르면 답이 **이 브라우저(localStorage)** 에 저장됩니다. 서버로는 아무것도 보내지 않습니다.
- 같은 컴퓨터·같은 브라우저로 다시 열면 저장한 답이 그대로 나옵니다. 저장하지 않고 탭을 닫으려 하면 한 번 묻습니다. 마지막 단계의 **저장한 답 지우기**로 지울 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `lib.js` · `app.js` · `style.css` | 이론 시뮬레이션 (데이터, 그래프, 단계) |
| `core.js` | 화면 엔진: 단계 이동, 슬롯 갱신, 끌기, 진행률 |
| `ws.js` | 빈칸, 단계별 배치, 정답이 보이는 부분 숨김, 저장하기 |
| `ws.css` | 빈칸 · 저장하기 버튼 · 배치 모양 |
